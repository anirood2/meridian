# Meridian demo

Locked in up front. Released on approval. Paid anywhere.

A working concept demo of Meridian: one API that lets platforms guarantee pay for contractors abroad. The client's money is locked in up front, released the moment the work is approved, and paid out in local currency or digital dollars.

Try it: https://anirood2.github.io/meridian/

- Four countries: Philippines (PHP via InstaPay), Mexico (MXN via SPEI), Nigeria (digital dollars), Poland (PLN via Express Elixir)
- Live exchange rates from the Frankfurter API where available; reference rates otherwise
- Money movement is simulated. No real funds move.

## Files
- `index.html`: landing page. Plays the 68-second story, then sends people to the demo
- `demo.html`: the working four-country demo
- `meridian.mp4`, `meridian.vtt`, `poster.jpg`: the story video, captions and poster

Static files, no build step. Hosted on GitHub Pages.
